# Support

PVault is a small, community maintained project. Please pick the right channel so bug reports stay findable.

## I have a question about using PVault

Use **GitHub Discussions** on the repository. Good topics: how flows work, how to get an OpenRouter key, how to move data to a new phone, how installing as an app works.

## Something is broken

Open a **GitHub issue** with:

- what you expected and what happened instead
- your device, browser and OS
- whether you were using the installed app or a browser tab
- whether you were online or offline
- console errors if you can get them

## I lost data

Check Settings, then Backup, and see whether an export exists. PVault stores everything in your browser's local storage for a single browser profile, so clearing site data, using private browsing, or switching browsers will lose it. Export a JSON backup regularly.

## I found a security issue

Do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## I want a new feature

Open a Discussion first, describing the problem rather than the solution. Features that require an account, a backend, or tracking are out of scope by design.

## Response times

This project is maintained in spare time. Expect a first reply within about a week. Complete, reproducible reports get answered first.
